# RAVEX RP Launcher — مشروع أندرويد مبدئي

## بيانات السيرفر
- الاسم: RAVEX RP
- العنوان: `45.138.16.241:8321`
- المنصة المستهدفة: Android / SA-MP Mobile

## ما الذي يفعله هذا المشروع؟
- واجهة مخصصة باسم RAVEX RP.
- يعرض عنوان السيرفر.
- زر ينسخ العنوان إلى الحافظة حتى تضيفه في تطبيق SA-MP Mobile.

## ما الذي لم يُنفّذ بعد؟
- لم يُضف اللوجو النهائي؛ الأيقونة الحالية مؤقتة.
- لا يوجد اتصال مباشر باللعبة حتى الآن. دعم فتح اللعبة والانضمام تلقائيًا يعتمد على نسخة SA-MP Mobile المثبتة، واسم الحزمة أو رابط الربط الذي تدعمه تلك النسخة.
- المشروع يحتاج إلى البناء والاختبار في Android Studio قبل توزيع APK.

## فتح المشروع
1. فك ضغط الملف.
2. افتح Android Studio واختر Open.
3. اختر مجلد `RAVEX_RP_Launcher`.
4. انتظر Gradle Sync.
5. من Build اختر Build APK(s).

إذا ظهر طلب تثبيت Android SDK، ثبّت Android SDK Platform 35 من SDK Manager.

## طريقة استخراج APK تلقائيًا عبر GitHub Actions
1. ارفع ملفات هذا المشروع إلى مستودع GitHub جديد (Repository)، مع تضمين مجلد `.github`.
2. افتح تبويب **Actions** في المستودع وفعّل Actions إذا طُلب ذلك.
3. اختر **Build RAVEX RP APK** ثم **Run workflow**.
4. بعد نجاح التشغيل، افتح نتيجة التشغيل وابحث عن **Artifacts** ونزّل `RAVEX-RP-debug-apk`.
5. فك ضغط الملف الناتج، وسيكون بداخله `app-debug.apk`.

هذه العملية تنشئ نسخة Debug للتجربة. لم يتم توقيع نسخة Release مخصصة للنشر في المتجر.
